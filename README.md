# JOBBY AI — India's Ultimate AI Opportunity Finder 🚀

> **Created with ❤️ by Vaibhav Sonava**

**JOBBY AI** is an advanced, ultra-fast, and highly accurate AI agent built to help students, entrepreneurs, and professionals in India discover and auto-apply for opportunities they never knew existed.

## 🔥 Key Features

- **200+ Real Indian Opportunities**: Including Scholarships, Government Schemes, Grants, Skill Programs, Startup Programs, and State Subsidies.
- **Smart AI Matching Engine**: Evaluates your profile (education, income, age, category, state, skills, interests) to find the perfect matches.
- **Real-Time Workflow Pipeline**: Visual processing from analyzing your profile to ranking results.
- **Auto-Apply Ready**: Get direct, official portal links for all your matches.
- **Premium UI**: Stunning dark mode, glassmorphism, and beautiful micro-animations for an exceptional user experience.
- **Blazing Fast**: Powered by Next.js 14 App Router and a multi-factor matching algorithm.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Pure CSS Modules with Glassmorphism
- **Backend**: Next.js API Routes + Custom In-Memory DB
- **Deployment**: Ready for Vercel

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/jobby-ai.git
   cd jobby-ai
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
